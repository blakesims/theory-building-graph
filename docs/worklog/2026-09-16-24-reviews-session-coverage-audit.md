# Session acceptance coverage audit

Historical note, 2026-09-16. Original path: `reviews/SESSION-COVERAGE-AUDIT.md`.

Cold-start recall does not establish sequential authoring behavior. Authored replay is mechanical evidence, not an observed interview. A written next command does not establish execution order. Browser observability needs separate evidence. Full agent coverage requires case-bound grades and actual source, tool and state artifacts. Scoped passes must disclose failures elsewhere in their parent session.
