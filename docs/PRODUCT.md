# Product

## Register

product

## Users

Blake and an agent collaborating on the theory of Morphisms. The human follows the
conversation and inspects changes; the agent authors and retrieves the graph.

## Product Purpose

Make current design statements, uncertainty, evidence and revisions inspectable.
The lightweight CLI is the primary authoring interface. The browser shows the same
durable graph and helps the human check what changed.

## Brand Personality

Plain, inspectable, restrained. These are working principles from the design
session, not a new visual identity.

## Anti-references

Avoid the prior column layout and a document dominated by history. Blake requested
an Obsidian-like network view with entities as hubs, colors distinguishing types,
and the graph using most of the screen.

## Design Principles

- Preserve the human's theory and distinguish it from an agent's interpretation.
- Make changes findable by stable ID and revision.
- Keep history available without making it the default view.
- Show uncertainty and check limits alongside results.
- Preserve the existing graph, inspector and type-color conventions.

## Accessibility & Inclusion

Existing implementation supports keyboard search, visible focus, text labels in
addition to color, and reduced motion. No additional user-specific access needs
have been stated. Continue those behaviors when adding inspector details.
