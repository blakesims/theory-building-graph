# Theory graph build

Historical note, 2026-09-16. Original path: `docs/BUILD-REPORT.md`.

The original build established atomic audited edits, bounded retrieval, explicit dependencies, finite pattern checks, and replay of authored transition models. Recorded acceptance covered 80 cases and 22 criteria, including independently graded participant artifacts. Mechanical tests are not agent behavior evidence. Original trials exposed misattribution, premature acceptance, extra reads and question-scope mistakes. Failed trials remain preserved. Graph/prose comparisons did not establish graph superiority. Both recovered the core change, and prose was cheaper in the measured maintenance pair. Human review time was not measured. This is not the Morphisms runtime or a proof of prose fidelity.
